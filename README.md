# UPI Fraud Transaction Over India

## Project Overview
This Power BI project analyze digital payment fraud cases by identifying fraud trend, affected payment method, victim demographics, Financial losses and geographical distribution.

## Dashboard Pages

### 1. Overview
- Money lost by types of scam
- Year by year money lost comparison
- Money lost by year and month comparison
- Money lost by types of devices
- Linked bank sorted by victim

### 2. Overview-2
- Money lost by fraud lure
- Segregating the Money lost by Victim Occupation
- Sorted Recovery status by victim
- Transaction type
- OTP shared

## Features
- DAX queries, Power Query 
- Data Cleaning, Data Modelling, Data Visualization, KPI cards
- Interactive dashboard using slicers,filters,charts,Dropdown etc.

## Insights
- Decreased Year by year money lost
- Highest scam has occured in SBI Bank
- Android users are highly affected
- Scam is affected by OTP not shared
- Daily wages are least affected by scam.
